# 13. 동시 청산 시스템 전략서

## 목적
프리미엄이 충분히 형성되면 **국내 현물 매도 + 해외 숏 청산을 동시에 실행**하여 수익을 확정한다.
시차가 발생하면 헤지가 풀려 방향성 리스크에 노출되므로, **동시성**이 핵심.

## 청산 타이밍 판단

### 12번에서 받는 청산 추천 조건
```
청산 실행 조건 (모두 충족):
  1. premium_pct > target_premium (등급별 상이)
  2. premium_velocity 둔화 (피크 근접)
  3. 호가창에 충분한 유동성 존재
  4. 거래량 스파이크 감지

target_premium 기본값:
  S등급: 15%+
  A등급: 10%+
  B등급: 5%+

조기 청산 조건:
  - 프리미엄 급락 시작 (피크 대비 -30% 하락)
  - 입출금 재개 임박 공지
  - 숏 펀딩비 누적이 예상 수익 대비 50% 초과
```

### 분할 청산 전략
```
프리미엄 구간별 분할 청산:

보수적 모드:
  프리미엄 10% 도달: 30% 청산
  프리미엄 20% 도달: 30% 추가 청산
  프리미엄 30%+ 도달: 잔여 전량 청산

공격적 모드:
  피크 감지 시그널 전까지 홀딩
  피크 감지 → 전량 일괄 청산
```

## 동시 청산 실행 로직

### 1. 사전 준비
```
청산 준비 상태 (pre-liquidation):
  1. 국내 거래소 현물 매도 주문 사전 세팅 (limit order)
  2. 해외 거래소 숏 청산 주문 사전 세팅 (limit order)
  3. 양쪽 API 연결 상태 확인
  4. 양쪽 주문 사이즈 일치 확인
```

### 2. 동시 실행
```
청산 트리거 시:
  T+0ms: 국내 현물 매도 주문 제출 (시장가)
  T+0ms: 해외 숏 청산 주문 제출 (시장가) [동시 발송]

  목표: 양쪽 체결 시차 < 1초

실행 방식:
  - 비동기 병렬 API 호출
  - 양쪽 모두 시장가 (체결 속도 우선)
  - 부분 체결 시 잔여 수량 즉시 재주문
```

### 3. 체결 확인 및 수량 정합
```
양쪽 체결 완료 후:
  domestic_filled_qty vs overseas_closed_qty 비교

IF 불일치:
  차이분 즉시 추가 주문
  예: 국내 10000개 매도, 해외 9500개만 청산
  → 해외 500개 추가 숏 청산

IF 한쪽 체결 실패:
  다른 쪽도 즉시 취소 시도
  실패 알림 + 수동 개입 요청
```

### 4. 슬리피지 관리
```
소형 알트는 유동성 낮으므로:
  - 국내: 호가창 1% depth 확인 후 청산 수량 결정
  - 수량이 1% depth 초과 시 분할 청산 (3~5회)
  - 각 분할 간격: 10~30초

해외:
  - 선물 유동성 상대적으로 풍부
  - 단, OI 낮은 코인은 주의
  - OI < $1M이면 분할 청산
```

## 시나리오별 청산

### 일반 청산 (프리미엄 캡처)
```
프리미엄 충분 → 양쪽 동시 청산 → 수익 확정
가장 흔한 시나리오
```

### 입출금 재개 임박 청산
```
입출금 재개 공지 감지 시:
  → 프리미엄 급락 예상 (아비트라지 재개)
  → 즉시 전량 청산
  → 재개 공지 감지는 03번에서 역으로 모니터링
```

### 해킹 시나리오 홀딩 후 청산
```
해킹 → 패닉셀 → 역프리미엄 → 추매 → 입출금 재개 → 수렴
  → 수렴 후 청산 (14번과 연동)
  → 시간이 오래 걸릴 수 있음 (수일~수주)
```

## 데이터 의존성
- `12-premium-realtime-tracker`: 프리미엄 데이터, 피크 감지
- `09-delta-neutral-position`: 활성 포지션 정보
- `15-short-liquidation-safety`: 숏 청산가 상태 확인
- `18-notification-system`: 청산 결과 알림

## 주의사항
- 동시 청산 실패 시 한쪽만 청산되면 방향성 리스크 노출 → 즉시 알림 + 수동 개입
- 거래소 API 장애 대비 백업 실행 경로 (웹 UI 수동 청산 가이드)
- 야간/새벽 청산 시 모바일 알림 필수
