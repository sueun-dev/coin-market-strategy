# 01. Governance Proposal Monitor
Cosmos SDK chain /gov/proposals polling, SoftwareUpgradeProposal filter, block height to estimated time calculation
Lead time: 3 days to weeks

Standalone Telegram:
- Preferred env keys: `GOVERNANCE_TELEGRAM_BOT_TOKEN`, `GOVERNANCE_TELEGRAM_CHAT_ID`
- Fallback env keys: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
- Test: `python main.py --test-telegram`
