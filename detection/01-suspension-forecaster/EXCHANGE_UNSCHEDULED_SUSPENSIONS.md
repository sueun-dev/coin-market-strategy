# Exchange Unscheduled Suspensions

- Generated at: 2026-04-07
- Meaning: only sudden or same-day `입출금 일시 중단` / `입출금 일시 지연` notices were included.
- Excluded: pre-announced network upgrades, hard forks, token swaps, rebrandings, and clearly scheduled maintenance.
- Upbit note: official notice titles and URLs were verified from Upbit, but dates/body details were captured from Bloomingbit mirror pages that link back to the original Upbit notice.
- Bithumb note: dates and reasons were read from official notice pages or official indexed snippets.

## Inclusion Rule

- Include when the notice says or implies the suspension/delay was triggered immediately by a live issue.
- Typical triggers included:
  - network issue
  - block generation stop
  - wallet system issue / same-day wallet system check
  - security issue
  - withdrawal surge

## What This Means For 01

- `돌발형`은 대체로 체인 공지보다 거래소 공지와 wallet status가 거의 동시에 바뀌는 케이스입니다.
- `예정형 업그레이드`와 달리, 선행 예고가 거의 없거나 같은 날 공지가 뜹니다.
- 자주 반복된 유형은 `블록 생성 중단`, `네트워크 이슈`, `월렛 시스템 점검`, `보안 이슈`, `출금량 급증`입니다.
- 실전 감시는 GitHub보다 `공식 status`, `거래소 공지`, `체인 블록 생성 상태`, `보안 이슈 채널`이 더 중요합니다.
